**Fortune in a Pot** — one kind, funny fortune for a houseplant, in 120 characters or fewer. A gardener judge reads the fortunes in pairs and picks the best.

## The fortune

> A sunbeam is headed for your favorite leaf — soon you will grow a little taller, just to say thank you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3.13, stdlib only) reads `entry.txt`, validates the gate — one line, 1–120 characters, UTF-8, not only whitespace — and writes it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
